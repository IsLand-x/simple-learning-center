# 按钮尺寸检查（2026-09-26）

本轮检查覆盖 `src/` 下的 Button、原生 button 及 `src/styles/` 中的对应规则。普通操作使用 Semi 默认尺寸，紧凑操作保留组件的 `size="small"`，不额外设置按钮宽高、内边距、字号或行高；此规则也适用于移动端。

## 已清理的覆盖

- 阅读器：保存到资源库、移除资源、重试、快捷提示词、新建对话、AI 设置、返回原进度、标题栏操作、正文选区按钮、Markdown 编辑工具栏及颜色选择按钮。
- 设置：模型编辑、账号、阅读助手、联网搜索、OAuth、OpenAPI、MCP 和机器信息操作；同时删除 API Key 导入导出入口的遗留样式与接口。
- 书架与书单：导入书籍、导入弹窗操作、书单操作、书单内移除和回收站按钮。
- RSS 与视频：移动标题栏操作、时间筛选、视频返回和字幕模式按钮。
- 图片查看器：放大、缩小、复位和关闭按钮。

主导航、阅读/视频的底部功能栏、目录/资源列表行、拖动手柄、图片入口及阅读样式预览卡片承载专用布局，保留其结构尺寸。这些控件不作为普通操作按钮的尺寸参考。未扩大现有样式例外或改变全局 CSS 导入顺序。

## 验证方法

E2E 的普通按钮检查改为与当前安装版本的 Semi 原生按钮比较高度、内边距、字号及行高，避免继续把项目里的 44px 覆盖当作正确行为。资源库用例新增双击重命名、键盘编辑、空标题、失败重试、刷新恢复及原对话图片保留的检查；设置用例覆盖入口删除与四种屏幕宽度的浅深色模式。

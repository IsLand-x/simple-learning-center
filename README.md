# 学习中心

一个本地优先的个人阅读与学习 Web App。目前项目聚焦“读书”场景，支持在浏览器中导入 EPUB、记录阅读进度、整理笔记、高亮和评论，并通过 OpenAI 兼容接口与 AI 助手讨论当前书籍。

所有书籍、阅读记录、笔记、对话和模型配置默认保存在当前设备，不依赖业务后端。

## 主要功能

### 书架

- 批量导入 EPUB，书籍文件保存在浏览器 IndexedDB 中。
- 卡片式书架，支持按书名或作者搜索。
- 支持“全部”“阅读中”“已读完”筛选。
- 展示封面、作者、当前章节、阅读进度和最近阅读时间。
- 删除书籍时同步清理该书的笔记、高亮、评论、AI 对话和阅读记录。

### 阅读器

- EPUB 分页阅读，并内置演示书籍用于本地调试。
- 支持目录跳转、上一页/下一页和方向键翻页：
  - `←` / `↑`：上一页
  - `→` / `↓`：下一页
- EPUB 阅读区使用开源 `epub.js` 的连续分页管理器和原生 Snap 手势，预加载相邻内容并处理触屏左右翻页；触控板双指横向滑动在整本书范围共享手势锁，一次完整手势只翻一页。
- 工具栏、方向键和触控板直接调用 `epub.js` 自带的翻页队列；支持 View Transition 的浏览器会对完整阅读画布执行首尾相接的整页平移动画，不改变 EPUB 内部滚动和排版位置。
- 自动保存章节、页码、百分比和 EPUB CFI；刷新或重新进入书籍时恢复到最后阅读页面。
- 顶部标题栏提供返回书架、目录展开、上一页、下一页和阅读模式入口；阅读状态仅展示整体进度与当前章节。
- 左侧目录、阅读区域和右侧辅助面板均可按需展开、收起或调整宽度。
- 使用 Allotment 实现可拖拽的分栏布局。
- 提供经典宣纸、简净阅读、杏仁手札、青瓷护眼、暮蓝夜读、米白宋韵、云水蓝笺和墨夜宋读八套阅读预设；不同预设会自动搭配无纹理、细腻纸纹或柔和颗粒。
- 支持自定义字体、纸张颜色、字体颜色、纸张纹理、文字大小和松紧程度，修改后实时预览并保存在当前设备；点击阅读正文会自动收起阅读设置弹层。
- 可选字体包括系统宋体、思源宋体、霞鹜文楷、霞鹜 Bright、思源黑体和苹方；思源宋体适合长篇正文，霞鹜 Bright 适合较轻松的手札风格。
- 苹方只调用设备已安装字体，不随项目分发；未安装时会自动使用思源黑体回退。

### 高亮、评论与原文引用

- 选中正文后，在选区附近显示“提问”“高亮”“评论”操作栏。
- 高亮基于 EPUB CFI 保存，不依赖屏幕像素位置，调整面板宽度后仍能对应原文。
- 点击“评论”可直接在选区附近记录见解；编辑期间原文保持高亮，可按 `Cmd + Enter` 保存，评论型高亮不会出现在普通高亮列表。
- 带评论的正文标记会在右上角显示 Semi Design 评论图标；点击后可以查看或编辑评论。
- 点击普通高亮可取消高亮、在高亮面板中定位，或就地添加评论；新增高亮不会自动展开侧栏。
- 右侧“高亮”和“评论”面板默认只展示内容与元信息；右键列表项可从鼠标位置打开删除菜单，删除评论仍会进行二次确认。
- 选中文字后提问时，原文会作为独立引用标签加入输入框，不会和用户问题混在一起。

### AI 助手

- 设置页通过独立 Tab 管理 AI 模型和联网搜索配置。
- 模型与联网搜索配置默认以只读横条展示，点击编辑后才显示可编辑表单。
- 支持管理多个 OpenAI 兼容模型配置。
- 每个配置可设置名称、Base URL、API Key 和多个模型。
- 阅读器中先选择供应商，再选择对应模型。
- 使用 Vercel AI SDK 的 OpenAI Compatible Provider，在浏览器中直接请求 `/chat/completions` 接口，不再依赖 ACP、Codex CLI 或 Kimi CLI 桥接服务。
- 支持流式响应；兼容端点未返回 SSE 时也可读取普通 JSON 响应。
- 使用 Semi Design AI Chat 组件展示用户消息、助手消息、模型思考内容和工具调用过程。
- 对话区左侧按用户发言轮次展示快速导航横条，悬停可预览原话，点击可跳转到对应消息。
- Agent 可以按需调用以下本地只读工具：
  - 当前书籍与目录
  - 当前章节和当前可见正文
  - 当前设备保留的书籍笔记
  - 当前书籍高亮及评论
  - 阅读时长与阅读历史
- 支持按需搜索整本 EPUB，并继续读取命中段落的相邻上下文。
- 支持通过 Jina Search 搜索互联网，并通过 Jina Reader 读取搜索结果网页正文。
- 书籍全文会在第一次搜索时于当前设备建立分段索引，不会为了索引上传整本书。
- 收起再展开 AI 侧栏时继续当前对话；刷新页面或离开阅读详情后重新进入时开启新对话；当前对话已有内容时，可通过面板右上角主动新建。
- 支持创建新对话、继续历史对话，以及右键删除对话。
- 对话历史列表会展示所用模型、消息数量和最后更新时间。

> 思考过程和工具调用能否完整展示，取决于所选模型及兼容端点是否返回 `reasoning`、`reasoning_content` 和 `tool_calls` 等字段。

### 阅读轨迹

- 自动记录每次阅读的开始时间、结束时间和持续时长。
- 同一天的多段阅读记录会在界面中合并展示。
- 提供最近 12 周阅读热力图、累计阅读时间和每日阅读历史。

### 界面与 PWA

- 支持浅色和深色主题。
- 应用功能栏、书籍目录和阅读辅助侧栏均支持折叠。
- 支持安装为 PWA，并生成离线缓存、桌面图标和移动设备图标。
- 桌面 Chromium PWA 使用窗口控件叠加模式，将系统标题栏融入应用界面；不支持时自动回退到独立窗口模式。
- 安装按钮只在普通网页且设备上尚未安装应用时展示；在独立 PWA 窗口中自动隐藏。
- 支持原生安装提示的浏览器会在点击按钮后完成安装并打开本地应用；其他浏览器会提示从浏览器菜单安装。
- 适配常见桌面与窄屏尺寸。

## 数据保存与隐私

| 数据 | 保存位置 | 说明 |
| --- | --- | --- |
| EPUB 文件、书内搜索索引 | IndexedDB：`learning-center-db` | 书籍原文件与按需生成的全文分段索引仅保存在当前浏览器设备 |
| 书籍元数据、阅读进度、笔记、高亮、评论、对话、模型配置 | localStorage：`learning-center-state-v1` | Zustand 持久化状态，包含版本迁移 |
| 模型与联网搜索 API Key | localStorage | 浏览器直接请求配置的 AI 或搜索接口，不会发送到本项目的业务服务器 |
| PWA 静态资源 | Cache Storage | 由 Service Worker 自动更新 |

请注意：

- 清理浏览器站点数据会删除本地书籍和学习记录。
- 当前项目没有账号体系、云同步或跨设备备份。
- API Key 只适合保存在自己的可信设备上，请勿在公共电脑使用。
- AI 接口必须允许浏览器跨域访问（CORS），否则浏览器会阻止请求。
- Agent 调用联网工具时，搜索词或目标网址会发送给所配置的搜索服务；书内搜索则完全在当前设备执行。

## 本地开发

### 环境要求

- Node.js `^20.19.0` 或 `>=22.12.0`
- npm

### 安装与启动

```bash
npm install
npm run dev
```

默认访问地址：

```text
http://127.0.0.1:5173/
```

其他常用命令：

```bash
# 使用 Vite 默认主机配置启动
npm run dev:web

# 与 dev 相同，显式使用本地地址
npm run dev:local

# TypeScript 检查并生成生产构建和 PWA 文件
npm run build

# 预览生产构建
npm run preview

# 根据 public/app-icon.svg 重新生成 PWA 图标
npm run generate:pwa-assets
```

## 配置 AI 模型

1. 打开左侧一级导航中的“设置”。
2. 点击“添加模型”。
3. 填写模型配置名称、OpenAI 兼容 Base URL、API Key 和模型列表。
4. 保存后进入任意书籍，打开右侧“AI 助手”。
5. 在输入框左下角选择模型并开始对话。

如需联网搜索，在设置页切换到“联网搜索”Tab，点击配置横条右侧的编辑按钮并填写 Jina API Key。配置后，Agent 会在问题需要书外资料或最新信息时按需调用 `web_search` 和 `read_web_page`；没有配置时，书内搜索及其他本地工具仍可正常使用。

Base URL 可以填写版本根路径，例如：

```text
https://api.openai.com/v1
```

应用会自动请求：

```text
POST https://api.openai.com/v1/chat/completions
```

如果填写的地址已经以 `/chat/completions` 结尾，则会直接使用该地址。

## 项目结构

├── data/              # 本地演示书籍

└── types.ts           # 领域类型定义

## 当前限制

- 仅支持 EPUB，暂不支持 PDF、MOBI 等格式。
- 数据仅保存在当前浏览器，暂不提供导入导出和云同步。
- 不同 EPUB 的排版结构差异较大，少数书籍可能需要单独兼容。
- 思源宋体、思源黑体、霞鹜文楷和霞鹜 Bright 均采用开放字体许可并按需加载；首次使用时需要网络，加载成功后可由浏览器缓存。
- AI 能力取决于所配置端点的 OpenAI 兼容程度、CORS 设置和模型能力。

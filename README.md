# 学习中心

一个本地优先的个人阅读与学习 Web App。目前项目聚焦“读书”场景，支持在浏览器中导入 EPUB、记录阅读进度、整理笔记和划线，并通过 OpenAI 兼容接口与 AI 助手讨论当前书籍。

所有书籍、阅读记录、笔记、对话和模型配置默认保存在当前设备，不依赖业务后端。

## 主要功能

### 书架

- 批量导入 EPUB，书籍文件保存在浏览器 IndexedDB 中。
- 卡片式书架，支持按书名或作者搜索。
- 支持“全部”“阅读中”“已读完”筛选。
- 展示封面、作者、当前章节、阅读进度和最近阅读时间。
- 删除书籍时同步清理该书的笔记、划线、AI 对话和阅读记录。

### 阅读器

- EPUB 分页阅读，并内置演示书籍用于本地调试。
- 支持目录跳转、上一页/下一页和方向键翻页：
  - `←` / `↑`：上一页
  - `→` / `↓`：下一页
- 自动保存章节、页码、百分比和 EPUB CFI；刷新或重新进入书籍时恢复到最后阅读页面。
- 左侧目录、阅读区域和右侧辅助面板均可按需展开、收起或调整宽度。
- 使用 Allotment 实现可拖拽的分栏布局。
- 支持字号、行高、阅读背景和正文字体设置。
- 可选字体包括系统宋体、思源宋体、思源黑体、仿宋、苹方、小米兰亭 / MiSans、微软雅黑、霞鹜文楷和霞鹜文楷屏幕版。
- 苹方、小米兰亭等商业字体只调用设备已安装字体，不随项目分发；未安装时会自动使用开源字体回退。

### 划线、笔记与原文引用

- 选中正文后，在选区附近显示“提问”“高亮”“笔记”操作栏。
- 高亮基于 EPUB CFI 保存，不依赖屏幕像素位置，调整面板宽度后仍能对应原文。
- 可在右侧面板查看、定位和删除划线。
- 支持新建、编辑和删除读书笔记。
- 选中文字后提问时，原文会作为独立引用标签加入输入框，不会和用户问题混在一起。

### AI 助手

- 在设置页管理多个 OpenAI 兼容模型配置。
- 每个配置可设置名称、Base URL、API Key 和多个模型。
- 阅读器中先选择供应商，再选择对应模型。
- 浏览器直接请求 OpenAI 兼容的 `/chat/completions` 接口，不再依赖 ACP、Codex CLI 或 Kimi CLI 桥接服务。
- 支持流式响应；兼容端点未返回 SSE 时也可读取普通 JSON 响应。
- 使用 Semi Design AI Chat 组件展示用户消息、助手消息、模型思考内容和工具调用过程。
- Agent 可以按需调用以下本地只读工具：
  - 当前书籍与目录
  - 当前章节和当前可见正文
  - 当前书籍笔记
  - 当前书籍划线
  - 阅读时长与阅读历史
- 支持创建新对话、继续历史对话，以及右键删除对话。
- 对话历史列表会展示所用模型、消息数量和最后更新时间。

> 思考过程和工具调用能否完整展示，取决于所选模型及兼容端点是否返回 `reasoning`、`reasoning_content` 和 `tool_calls` 等字段。

### 阅读轨迹

- 自动记录每次阅读的开始时间、结束时间和持续时长。
- 同一天的多段阅读记录会在界面中合并展示。
- 提供最近 12 周阅读热力图、累计阅读时间和每日阅读历史。

### 界面与 PWA

- 支持浅色和深色主题。
- 应用功能栏、书籍目录和阅读辅助侧栏均支持折叠。
- 支持安装为 PWA，并生成离线缓存、桌面图标和移动设备图标。
- 适配常见桌面与窄屏尺寸。

## 数据保存与隐私

| 数据 | 保存位置 | 说明 |
| --- | --- | --- |
| EPUB 文件 | IndexedDB：`learning-center-db` | 书籍原文件仅保存在当前浏览器设备 |
| 书籍元数据、阅读进度、笔记、划线、对话、模型配置 | localStorage：`learning-center-state-v1` | Zustand 持久化状态，包含版本迁移 |
| API Key | localStorage | 浏览器直接请求配置的 AI 接口，不会发送到本项目的业务服务器 |
| PWA 静态资源 | Cache Storage | 由 Service Worker 自动更新 |

请注意：

- 清理浏览器站点数据会删除本地书籍和学习记录。
- 当前项目没有账号体系、云同步或跨设备备份。
- API Key 只适合保存在自己的可信设备上，请勿在公共电脑使用。
- AI 接口必须允许浏览器跨域访问（CORS），否则浏览器会阻止请求。

## 本地开发

### 环境要求

- Node.js `^20.19.0` 或 `>=22.12.0`
- npm

### 安装与启动

```bash
npm install
npm run dev
```

默认访问地址：

```text
http://127.0.0.1:5173/
```

其他常用命令：

```bash
# 使用 Vite 默认主机配置启动
npm run dev:web

# 与 dev 相同，显式使用本地地址
npm run dev:local

# TypeScript 检查并生成生产构建和 PWA 文件
npm run build

# 预览生产构建
npm run preview

# 根据 public/app-icon.svg 重新生成 PWA 图标
npm run generate:pwa-assets
```

## 配置 AI 模型

1. 打开左侧一级导航中的“设置”。
2. 点击“添加模型”。
3. 填写模型配置名称、OpenAI 兼容 Base URL、API Key 和模型列表。
4. 保存后进入任意书籍，打开右侧“AI 助手”。
5. 在输入框左下角选择模型并开始对话。

Base URL 可以填写版本根路径，例如：

```text
https://api.openai.com/v1
```

应用会自动请求：

```text
POST https://api.openai.com/v1/chat/completions
```

如果填写的地址已经以 `/chat/completions` 结尾，则会直接使用该地址。

## 当前限制

- 仅支持 EPUB，暂不支持 PDF、MOBI 等格式。
- 数据仅保存在当前浏览器，暂不提供导入导出和云同步。
- 不同 EPUB 的排版结构差异较大，少数书籍可能需要单独兼容。
- 首次使用在线开源字体时需要网络；加载成功后可由浏览器缓存。
- AI 能力取决于所配置端点的 OpenAI 兼容程度、CORS 设置和模型能力。
